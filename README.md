# Engenharia de Dados em AWS (Compass UOL)

Exercícios e práticas que fiz no programa de formação em Engenharia de Dados em AWS da Compass UOL (2022, 240 horas). Este repositório reúne o que é código meu; o material do curso não está aqui.

## O que o programa cobriu

| Semana | Tema | O que tem aqui |
|---|---|---|
| 1 | SQL | [Consultas sobre biblioteca e vendas](semana-1-sql/exercicios_biblioteca_e_vendas.sql): joins, agregações, `group by`, subconsultas |
| 2 | SQL avançado | [Exportação de resultados para CSV](semana-2-sql/consultas_exportacao_csv.sql) com `INTO OUTFILE` e `SPOOL` |
| 3 | Python | [Exercícios básicos (notebook)](semana-3-python/exercicios_parte1.ipynb) e [lista 2](semana-3-python/exercicios_lista2.md): listas, dicionários, funções, arquivos, JSON e classes |
| 4 | Python orientado a objetos | Desafio de leitura e análise do arquivo `actors.csv` (feito no curso, não publicado aqui) |
| 5 | AWS | Labs de EC2, VPC, S3, RDS, IAM e Lambda. [Passo a passo do RDS](semana-5-aws-rds/passo_a_passo_rds.md) |
| 6 | Análise de dados na AWS | EMR e serviços de analytics |
| 7 | Arquitetura de dados | Arquitetura Lambda e ETL com Talend |
| 8 | Big data | Hadoop e Spark com Docker: [Dockerfile](semana-8-spark/Dockerfile) com Jupyter e Spark |

## Tecnologias

SQL (MySQL), Python, Jupyter, AWS (EC2, VPC, S3, RDS, IAM, Lambda, EMR), Docker, Spark.
